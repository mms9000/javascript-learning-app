# Interactive JavaScript Learning Platform — SDD Documents

This folder contains the proposed Spec-Driven Development (SDD) baseline for an interactive website that teaches JavaScript from beginner fundamentals through object-oriented programming (OOP), preparing learners to approach unfamiliar JavaScript frameworks.

## Files

- `constitution.md` — highest-level principles and governance rules.
- `requirements.md` — MVP scope, functional requirements, constraints, and acceptance expectations.
- `curriculum-spec.md` — learning sequence, prerequisites, lesson structure, and assessment policy.
- `architecture-spec.md` — proposed application architecture and technical constraints.
- `feature-spec-playground.md` — detailed behavior and acceptance scenarios for the interactive code playground.
- `implementation-plan.md` — incremental work plan for delivering the first vertical slice and expanding the product.
- `release-checklist.md` — functionality, security, accessibility, and quality checks before a release.

## Status and intended use

These documents are a **proposed baseline**. They do not indicate that the website has been implemented, that tests have passed, or that the code execution design has been security-reviewed. Confirm technical choices before implementation, and update specifications when approved requirements change.

## Suggested workflow

1. Review the constitution and MVP requirements.
2. Confirm the curriculum and architecture decisions.
3. Implement the first lesson as a complete vertical slice.
4. Verify every acceptance criterion and document actual test results.
5. Add lessons and features incrementally through updated specifications.
